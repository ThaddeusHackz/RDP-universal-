                    WELCOME TO THADD OS 1.0 (NEBULA)
                    One OS. All the Best.
═══════════════════════════════════════════════════════════════════

THADD OS is a universal Linux desktop that lives in the cloud.
It unites the best ideas of the Linux world — the stability and
lightness of Debian, the usability of Ubuntu, the elegance of
elementary OS, the minimalism of Arch and the power of Fedora —
into one always-on operating system.

HOW TO USE IT
─────────────
 • This desktop runs in your browser (via the THADD portal —
   one click, you are signed in automatically) AND in any RDP
   client (Microsoft Remote Desktop, Remmina, FreeRDP, Jump
   Desktop...) with the username + password from the portal.

 • Terminal commands worth trying:
     thadd            system overview
     thadd doctor     full self-diagnostic
     neofetch         system info with the THADD logo
     btop             gorgeous live system monitor
     thadd help       more commands

 • Installed highlights:
     Firefox ESR (browser), Thunar (files), Mousepad (editor),
     git, sudo, curl, htop, btop, neofetch, bat, duf, vim, nano.

 • Your data persists forever: /home is backed by a Railway
   volume, so files survive redeploys and restarts.

 • The desktop looks like this by design:
     XFCE 4.18 + Arc-Dark + Papirus-Dark icons + Inter fonts
     + Plank dock + conky HUD + Dracula terminal + starship.

THADD OS is CI-verified: every push builds the full system and
logs into it over a real RDP connection before it ships.
